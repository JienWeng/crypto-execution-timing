# Forecast-selection research draft

- `manuscript.pdf`: revised paper based on the frozen selection experiment.
- `appendices.pdf`: methods, mathematical proof, complete results and reproduction checks.
- `source/`: editable LaTeX, references, figures and tables.
- Experiment: `../../revisions/2026-09-20-selection/REPORT.md`.

This is a research draft for the proposed Applied Economics Letters submission, not a submitted or accepted paper. Current journal word-count and supplement requirements still need verification. The earlier matched-endpoint manuscript remains in `../applied-economics-letters/` for comparison. These are versions of the same research project, not independent papers for simultaneous submission.

Main finding: execution-based selection loses less than final-price selection in the SOL/BNB/XRP historical test. A simpler demeaned-path selector makes the same choices, and both lose against the no-signal baseline. Costs remain assumed. These qualifications are in the main text, not only the appendix.

PDFs are local review copies and are excluded from GitHub. Source, data and code accompany the public reproducibility project.
